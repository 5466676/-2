# تدريب مودل المعايدات

مصنّف ثنائي صغير (MobileNetV3-Small، نقل تعلّم) بيعطي احتمال إن الصورة
معايدة. المخرج النهائي: `assets/models/greeting_classifier.tflite`
(~1–2 MB بعد التكميم).

## 1. البيئة

```bash
cd training
python -m venv .venv
.venv\Scripts\activate          # ويندوز
# source .venv/bin/activate     # لينكس/ماك
pip install -r requirements.txt
```

## 2. البيانات

```
training/dataset/
  greeting/   صور معايدات — صباح الخير، جمعة مباركة، رمضان كريم، عيد مبارك…
  normal/     صور عادية
```

- **greeting**: أسهل مصدر هو ألبوم `WhatsApp Images` نفسه — انسخ منه
  المعايدات. كل ما كانت متنوعة أكثر (خطوط، ورود، خلفيات، GIF ثابتة) أحسن.
  مبدئيًا 500+ صورة كافية.
- **normal**: شغّل
  ```bash
  python build_normal.py --count 3000
  ```
  بينزّل COCO val2017 (~800MB مرة وحدة) وبياخد عينة عشوائية.
  **مهم:** ضيف كمان صور عادية من الواتساب نفسه — لقطات شاشة، فواتير،
  مستندات، صور منتجات — لأن هاي أكثر شي بيتلخبط فيه المودل مع المعايدات.

## 3. التدريب

```bash
python train.py --data dataset --epochs 30
```

مرحلتين: الرأس بس، بعدين ضبط ناعم لآخر 30 طبقة. بالآخر بيطبع الدقة
(precision) والاسترجاع (recall) عند العتبة 0.7 — نفس
`AppConfig.greetingThreshold` بالتطبيق. الدقة أهم من الاسترجاع: صورة عادية
انعلّمت غلط أسوأ من معايدة فاتت (وبكل الأحوال المستخدم بيراجع قبل المسح).

## 4. التصدير

```bash
python export.py
```

بيكتب `../assets/models/greeting_classifier.tflite` وبيتأكد إن الشكل مطابق
لتوقعات التطبيق:

| | الشكل | ملاحظات |
|---|---|---|
| المدخل | `[1, 224, 224, 3]` float32 | بكسلات RGB خام 0..255 — التطبيع جوّا المودل |
| المخرج | `[1, 1]` float32 | احتمال معايدة (sigmoid) |

التطبيق كمان بيقبل مخرج `[1, 2]` (= [عادية، معايدة]) ومدخل uint8، إذا حبيت
تجرب مودل تاني.
